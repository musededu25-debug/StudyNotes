# rg 使用笔记（Version 2.0）

> 本机版本：ripgrep 15.2.0（Apple Silicon）
> 一句话：rg 是 `grep` 的现代替代品——极速、默认尊重 `.gitignore`、输出干净，配合 fzf/bat 能做交互式代码搜索。

---

## 一、常用指令速查表（先记这张表）

| 命令 | 作用 | 示例 |
|------|------|------|
| `rg 关键词` | 搜文件**内容**（递归） | `rg zoxide` |
| `rg 关键词 路径` | 在指定路径搜 | `rg vue ~/Home/300-ProjectHome` |
| `rg -n 关键词` | 带行号 | `rg -n zoxide` |
| `rg -l 关键词` | 只列匹配的**文件名** | `rg -l zoxide` |
| `rg -c 关键词` | 每个文件匹配了几处 | `rg -c TODO` |
| `rg -t 类型 词` | 按文件类型 | `rg -t md brew` |
| `rg -g '*.md' 词` | 按文件名 glob | `rg -g '*.vue' function` |
| `rg -F 词` | 字面匹配（关掉正则） | `rg -F '--'` |
| `rg -w 词` | 整词匹配 | `rg -w fd` |
| `rg -o 词` | 只输出命中的片段 | `rg -o 'https\?://\S\+'` |
| `rg -C 3 词` | 上下文各 3 行 | `rg -C 3 zoxide` |
| `rg --hidden 词` | 连隐藏文件也搜 | `rg --hidden env` |
| `rg -uu 词` | 全放开（隐藏+忽略规则） | `rg -uu secret` |
| `fif 词` | 交互式：搜→选→跳到编辑器 | `fif zoxide` |

## 二、详细解释

### 1. 命令结构

```
rg   [选项]   [关键词]   [路径]
```

- **关键词**：默认是**正则**，匹配**文件内容**（不是文件名——那是 fd 的事）
- **路径**：从哪个目录开始递归搜，省略 = 当前目录

```bash
rg zoxide                     # 当前目录下，内容含 "zoxide" 的文件
rg zoxide ~/Home/200-MarkdownHome   # 在指定路径下搜
```

### 2. 三个默认行为 ⭐（和 fd 一模一样，因为是同一个作者）

rg 和 fd 都是 Rust 写的、同一作者，所以默认「洁癖」完全一致：

| 默认行为 | 含义 | 想关掉 |
|---------|------|--------|
| 尊重 `.gitignore` | 自动跳过 node_modules、build 等垃圾 | `-u` / `--no-ignore` |
| 跳过隐藏文件（点开头） | 不搜 `.env`、`.config` | `--hidden` |
| 跳过 `.git` 目录 | 不翻 Git 内部 | `-uu`（连隐藏+VCS 一起放开） |
| 大小写不敏感（smart-case） | `rg readme` 也能匹配 `README`，但有大写就区分 | `-s` |

> `-u` 是递进的：`-u`（不忽略）→ `-uu`（再搜隐藏）→ `-uuu`（连二进制也搜）。

### 3. 和 grep 的语法对比

| 需求 | grep（繁琐） | rg（直观） |
|------|-------------|-----------|
| 递归搜当前目录 | `grep -r 词 .` | `rg 词`（默认就递归） |
| 带行号 | `grep -n 词` | `rg -n 词` |
| 忽略 .gitignore | 要手动 `--exclude` 一堆 | 默认就忽略 |
| 只列文件名 | `grep -rl 词 .` | `rg -l 词` |

### 4. 两种输出格式 ⭐（fif 的灵魂）

rg 默认输出是「**给人看**」的，fif 内部需要「**给机器吃**」的。同一句 `rg zoxide`，加不同参数长这样：

**① 默认**（分组、无行号，人看舒服）：
```
.../5ZoXide/ZoXide-Version 2.0.md:> 一句话：zoxide 是「智能 cd」...
```

**② 加 `-n`**（多了行号，`文件:行号:内容`）：
```
.../5ZoXide/ZoXide-Version 2.0.md:3:> 本机版本：zoxide 0.10.0 ...
```

**③ 机器可读**（加 `--column --no-heading`，`文件:行:列:内容`）：
```
.../5ZoXide/ZoXide-Version 2.0.md:3:18:> 本机版本：zoxide 0.10.0 ...
                              ↑  ↑
                            行号 列号
```

- `--column`：加列号，凑成四段
- `--no-heading`：去掉 rg 默认的「文件名 + 空行」分组头，保证一行一条
- `--color=always`：**强制**颜色（管道里 rg 默认自动关色，加这个 fzf 才有颜色）

**这三种格式你平时只用 ①②，③ 是 fif 内部的齿轮**——它让 fzf 能按 `:` 把每行切成 `{文件}{行号}{列号}{内容}`。

### 5. 常用选项分组

#### 搜索范围
- `-t md` 按文件类型；`-g '*.md'` 按文件名 glob；`rg --type-list` 看全部类型
- `--hidden` 含隐藏文件；`-u`/`-uu`/`-uuu` 逐级放开忽略规则

#### 匹配方式
- `-F` 字面匹配（关正则）；`-w` 整词；`-o` 只输出命中段
- `-s` 强制区分大小写；`-i` 强制忽略大小写

#### 输出控制
- `-n` 行号；`-l` 只列文件名；`-c` 计数
- `-A 3` 命中后 3 行；`-B 3` 命中前 3 行；`-C 3` 前后各 3 行（最常用）
- 输出太多：`rg ... | less` 分页，或 `rg ... | bat` 高亮

### 6. 和 fzf/bat 联动（fif，呼应 ZoXide 笔记）

`fif`（已配进 `.zshrc`）就是 rg + fzf + bat 三者的流水线：

```
rg 搜出「文件:行:列:内容」 → fzf 选 → bat 预览 → 回车 nvim 跳到该行
```

一句话理解 fif 的组装过程：

```bash
rg vue                                          # 1 搜
rg -n --column --no-heading --color=always vue  # 2 变机器可读
rg ... | fzf --ansi --delimiter :               # 3 给 fzf 选
rg ... | fzf ... --preview 'bat ... {2} {1}'    # 4 bat 预览（{1}文件 {2}行号）
# 5 选中后 cut 取文件+行号，nvim "+行号" 文件  打开
```

其他更轻的联动：

```bash
rg -l 词 | fzf        # 只选「哪个文件」
rg --files | fzf      # 列出所有文件（相当于 rg 版的 fd）
rg 词 | bat           # 结果交给 bat 高亮分页看
```

## 三、进阶（按需了解）

- **正则陷阱与 `-F`**：`.` `*` `+` `?` `[` `(` `|` `^` `$` `\` 在正则里都是特殊符号。搜字面文本加 `-F` 最省心：`rg -F 'a.b'` 不会把 `.` 当「任意字符」。
- **`-o` 提取**：配合正则只输出命中部分，比如 `rg -o 'https\?://\S\+'` 从文本里抓出所有 URL。
- **`--replace` 替换**：`rg 词 --replace 新词`（只是替换显示，不动文件）。
- **`--files`**：列出所有会被搜索的文件，等于「rg 版的 fd」，也能 `rg --files | fzf`。
- **和 fd 的关系**：fd 找**文件名**、rg 找**内容**，同一个作者、同一套默认行为，配合使用是「先定位文件（fd）、再定位内容（rg）」。
