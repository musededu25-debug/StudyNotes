## 二、详细解释

### 1. eza 是什么

`ls` 的现代替代品，Rust 写的，是已停更的 `exa` 的继任。比 `ls` 多了：

- **彩色 + 图标**：文件类型、权限、Git 状态一目了然
- **树状视图**：`-T` 直接看目录层级，不用 `find` 或额外装 `tree`
- **智能默认**：目录排前面、更人性化的时间显示

### 2. 安装（本机还没装）

```bash
brew install eza
```

装完 `eza` 即可用。想直接替代 `ls`，加别名（见「三、进阶」）。

### 3. 和 ls 的区别

| 需求 | ls | eza |
|------|-----|-----|
| 彩色输出 | ❌ 要 `ls -G`（macOS） | ✅ 默认彩色 |
| 树状视图 | ❌ 没有 | ✅ `-T` |
| Git 状态 | ❌ | ✅ `--git` |
| 目录排前面 | ❌ | ✅ `--group-directories-first` |

### 4. 常用选项分组

#### 展示
- `-l` 长格式；`-a` 含隐藏（`-aa` 连 `.` / `..` 也显示）；`-1` 一行一个
- `-F`（`--classify`）给目录加 `/`、可执行加 `*` 后缀
- `--git` 显示 Git 状态（两列：暂存 + 未暂存）
- `--icons` 显示图标（需要 Nerd Font 字体，没有会乱码）

#### 树状
- `-T`（`--tree`）树状；`-L 2` 限制层级

#### 排序 / 过滤
- `-s 字段` 排序，字段有 `name`（名）、`size`（大小）、`modified`（时间，别名 `newest`/`date`/`time`）、`ext`（扩展名）等
- `-r` 反转排序（`-s modified -r` = 最旧在上）
- `-D` 只列目录；`-f` 只列文件
- `-t` 是「显示哪个时间戳」（默认 modified），**不是**排序

## 三、进阶（按需了解）

### 用别名替代 ls（可选）

装好后，在 `.zshrc` 加：

```bash
alias ls="eza"
alias ll="eza -l"
alias la="eza -la"
alias lt="eza -T"        # 树状
alias lg="eza -l --git"  # 带 Git 状态
```

改完 `source ~/.zshrc` 生效。建议先 `eza` 和 `ls` 并存用几天，习惯后再决定要不要全替换。

## 联动（呼应其他笔记）⭐

- **bat（007）**：eza 看「列表」（目录里有什么），bat 看「内容」（文件里写了什么），正好互补。常用组合：`eza -l` 找文件 → `bat 文件` 看内容。
- **rg（004）/ fd（005）**：fd 找文件名、rg 找内容，eza 负责「看目录结构」这一环，和它们一起构成完整的「找东西」工具链。
- **tldr（003）**：忘了 eza 的选项就 `tldr eza`。

---

## 总结：要不要用

- **推荐装**：`ls` 换成 `eza` 是零成本提升，看目录/树状/Git 状态都比 `ls` 强。
- **优先级**：低于 rg / fd（这两个是刚需），和 bat 同级，属于「锦上添花但很香」。
- **下一步**：`brew install eza`，装好后加别名。
