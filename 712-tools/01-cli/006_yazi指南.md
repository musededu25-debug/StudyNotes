# yazi 使用笔记（Version 2.0）

> 本机版本：yazi 26.9.1（Homebrew 2026-09-01，Apple Silicon）
> 一句话：yazi 是「终端里的访达」——全键盘操作的文件管理器，内置 zoxide 和 fzf，退出还能自动 cd，和终端无缝衔接。

---

## 一、常用按键速查表（先记这张表）

### 移动
| 按键 | 作用 |
|------|------|
| `j` / `k` | 下 / 上移动 |
| `l` / `h` | 进入目录 / 回上级目录 |
| `g` 再 `h` | 回主目录 `~` |
| `g` 再 `g` | 跳到顶部 |

### 文件操作
| 按键 | 作用 |
|------|------|
| `回车` | 进入目录 / 打开文件 |
| `.` | 显示 / 隐藏 隐藏文件 |
| `y` | 复制（yank） |
| `x` | 剪切 |
| `p` | 粘贴 |
| `d` | 删除到回收站（`D` 彻底删除） |
| `r` | 重命名 |
| `q` | 退出 |

### 复制路径（先按 `c`，再按第二下）⭐
| 按键 | 作用 |
|------|------|
| `c` 再 `c` | 复制**完整路径** |
| `c` 再 `f` | 复制**文件名** |
| `c` 再 `n` | 复制**名字**（去扩展名） |
| `c` 再 `d` | 复制**上级目录**路径 |

| 按键 | 作用 |
|------|------|
| `Z`（大写） | zoxide 跳历史目录 |
| `z`（小写） | fzf 搜当前目录树 |

## 二、详细解释

### 1. yazi 是什么

终端里的**文件管理器**，像图形界面的「访达」，但全程键盘、不用鼠标。适合「在终端里快速浏览 / 整理文件」，比一遍遍 `ls` + `cd` 快得多。

**打开方式**：终端敲 `yazi`（或本机配好的 `y`，见第 5 节）进入；`q` 退出。

### 2. 核心操作

- **移动**：`j`/`k` 上下、`l` 进入、`h` 退回上级（和 vim 一个手感），`回车` 打开。
- **隐藏文件**：按 `.` 切换显示/隐藏（看 `.env`、`.config` 这类点开头的文件）。
- **复制 / 剪切 / 粘贴**：`y` 复制、`x` 剪切、`p` 粘贴（vim 的 yank/paste 手感）。
- **回主目录**：`g` 打开「跳转」菜单，再按 `h` 回 `~`。

### 3. 复制路径的四种玩法 ⭐

这是 yazi 特别实用的一点：光标停在某个文件/目录上，先按 `c` 进入「复制」子菜单，再按第二下：

| 按键 | 复制什么 | 示例结果 |
|------|---------|---------|
| `c` 再 `c` | 完整路径 | `/Users/m/.../foo.md` |
| `c` 再 `f` | 文件名 | `foo.md` |
| `c` 再 `n` | 名字（去扩展名） | `foo` |
| `c` 再 `d` | 上级目录路径 | `/Users/m/.../` |

复制后回终端直接 `Cmd-V` 粘贴，配合 `z`、`rg`、`fd` 特别好用。

### 4. 内置 zoxide 和 fzf ⭐（和终端共用一套记忆）

新版 yazi 内置了 zoxide 和 fzf，**零配置**：

- `Z`（大写）= zoxide 跳转：弹出 fzf，浏览 zoxide 历史目录，选一个跳过去
- `z`（小写）= fzf 搜索：搜**当前目录树**里的文件/目录

> 注意大小写：`Z` 是历史目录（zoxide），`z` 是当前目录树（fzf）。和终端里的 `z 关键词` 是同一个记忆库。

### 5. 用 `y` 打开，退出自动 cd ⭐

默认退出 yazi 后，终端还停在原目录。本机已配好 `y` 函数，退出时自动 cd 到 yazi 里最后所在的目录：

```bash
y        # 用 y 代替 yazi 打开
```

- 直接敲 `yazi`：退出后终端停在原地
- 敲 `y`：退出后终端「落」在最后浏览的目录

> 坑：在 yazi 里跳了目录、按 `q` 却回到原点 → 因为用了 `yazi` 而不是 `y`。魔法全在 `y` 这个包装函数里（见「三、进阶」）。

## 三、进阶（按需了解）

### 让 yazi 也「喂」zoxide 数据库

默认 yazi 只**读** zoxide 数据库、不往里写。本机已建 `~/.config/yazi/init.lua`，让 yazi 里 cd 逛过的目录也进数据库：

```lua
require("zoxide"):setup {
    update_db = true,
}
```

这样「终端 `z` 记的目录」和「yazi 里逛的目录」双向互通，一处积累、两处受益。

### `y` 函数的原理

`y` 就是给 yazi 塞了个 `--cwd-file`，退出后读那个临时文件再 `cd` 过去（函数体在 `~/.zshrc`，`type y` 可查看）。

---

## 联动（呼应其他笔记）⭐

- **zoxide（002）**：yazi 里 `Z` 和终端里 `z` 共用同一份 zoxide 数据库；`init.lua` 还能让 yazi 反向喂数据。
- **fzf**：yazi 内置 fzf，`z` 搜文件；和终端里 fzf 的 `Ctrl-T` / `Alt-C` 是同一个思路。
- **配合 `z` 的完整工作流**：终端 `z project` 跳过去 → `y` 打开浏览 → 退出自动 cd 停在那里，全程不用打全路径。

---

## 总结：要不要用

- **必用**：想要「终端里的访达」就用，内置 zoxide/fzf，和终端无缝互补。
- **学习成本**：低。记住 `jklh`、`.`、`y/x/p`、`Z`/`z`、`q` 这几个键就能用起来。
- **和访达的关系**：不是替代，是「终端场景」的文件浏览，适合命令行工作流。
