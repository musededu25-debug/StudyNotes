# fd 使用笔记（Version 2.0）

> 本机版本：fd 10.5.0（Apple Silicon）
> 一句话：fd 是 `find` 的现代替代品——语法直观、默认忽略 `.gitignore` 和隐藏文件、速度快一个数量级。

---

## 一、常用指令速查表（先记这张表）

| 命令 | 作用 | 示例 |
|------|------|------|
| `fd 关键词` | 找文件名含关键词的文件 | `fd vue` |
| `fd` | 列出当前目录所有文件（不含隐藏） | `fd` |
| `fd 词 路径` | 在指定路径下找 | `fd md ~/Home/200-MarkdownHome` |
| `fd -e 扩展名` | 按扩展名找 | `fd -e md` |
| `fd -t d` | 只找目录 | `fd -t d` |
| `fd -H 词` | 包含隐藏文件 | `fd -H env` |
| `fd -I 词` | 不忽略 `.gitignore`（含 node_modules） | `fd -I node_modules` |
| `fd -d 深度` | 限制搜索深度 | `fd -d 2` |
| `fd -E 目录` | 排除某个目录 | `fd -E node_modules` |
| `fd 词 -x 命令` | 对每个结果执行命令 | `fd -e jpg -x ls -l` |

---

## 二、详细解释

### 1. 命令结构

```
fd   [关键词]   [路径]
```

- **关键词**：默认是正则，匹配**文件名**（不是文件内容）
- **路径**：从哪个目录开始找，省略 = 当前目录

```bash
fd vue                 # 当前目录下，文件名含 "vue" 的
fd vue ~/Home/300-ProjectHome   # 在指定路径下找
```

### 2. 三个默认行为 ⭐（和 find 最大的不同）

fd 开箱就有三个「贴心」的默认行为，find 全都做不到（要手动加一堆参数）：

| 默认行为 | 含义 | 想关掉 |
|---------|------|--------|
| 忽略 `.gitignore` 里列的文件 | 自动跳过 node_modules、build 等垃圾 | `-I` / `--no-ignore` |
| 忽略隐藏文件（点开头） | 不显示 `.env`、`.config` 这些 | `-H` / `--hidden` |
| 忽略 `.git` 目录 | 不翻 Git 内部文件 | `-I` |
| 大小写不敏感 | `fd readme` 也能匹配 `README.md` | `-s` |

> 注意「忽略 node_modules」不是特殊规则，而是因为 node_modules 通常写在 `.gitignore` 里，fd 尊重了它。**这也是 fd 比 `find` 快、且输出干净的根本原因。**

### 3. 和 find 的语法对比

| 需求 | find（繁琐） | fd（直观） |
|------|-------------|-----------|
| 找所有 .md 文件 | `find . -name "*.md"` | `fd -e md` |
| 找目录 | `find . -type d` | `fd -t d` |
| 忽略 .gitignore | `find . -not -path "./node_modules/*" ...` | 默认就忽略 |
| 找隐藏文件 | `find . -name ".*"` | `fd -H` |

### 4. 常用选项分组

#### 搜索范围
- `-H` 包含隐藏文件；`-I` 不忽略 `.gitignore`；`-u` 两者都要（`-H -I` 的简写，全搜）
- `-d 2` 限制最深 2 层；`-E node_modules` 排除某目录

#### 匹配方式
- `-g '*.vue'` 用 glob 通配符；默认是正则
- `-p` 让关键词也匹配完整路径（默认只匹配文件名）
- `-s` 强制区分大小写

#### 过滤类型
- `-t f` 文件 / `-t d` 目录 / `-t x` 可执行文件 / `-t e` 空文件
- `-e md` 按扩展名（等价 `-t f -e md`）
- `-S +100k` 按大小（`+` 大于等于，`-` 小于等于）
- `--changed-within 2d` 最近 2 天改过的

#### 执行（进阶，批量操作神器）
- `-x 命令` 对**每个**结果执行一次命令，`{}` 是结果占位符
- `-X 命令` 把**所有**结果拼成参数，一次执行

```bash
fd -e md -x wc -l {}      # 每个 md 文件单独统计行数
fd -e md -X wc -l         # 所有 md 文件一起统计（更快）
fd -e jpg -x convert {} {.}.png   # 批量 jpg 转 png
```

### 5. 和 fzf 的配合（呼应 ZoXide 笔记）

fzf 的 `Ctrl-T`（找文件）/ `Alt-C`（找目录）底层就用 fd 扫描（见 `4ZoXide` 笔记「三、进阶」）。所以学好 fd 的 `-H`、`-E`、`--strip-cwd-prefix`，就是直接优化 fzf 的搜索体验。

---

## 三、进阶（按需了解）

- **`-x` 批量处理**：`fd 词 -x 命令` 是 fd 最「大神」的用法，可以替代很多 `for` 循环和 `xargs`。
- **`-0` + xargs**：`fd -0 词 | xargs -0 命令`，处理带空格/特殊字符的文件名更安全。
- **`--exact`**：精确匹配整个文件名（`fd --exact index.html` 不会匹配 `index.html.bak`）。
- **`--and 词`**：同时满足多个关键词。
- **全局忽略文件**：在家目录放一个 `~/.fdignore`（类似 `.gitignore` 语法），列进 node_modules、.git 等，fd 会全局生效。
