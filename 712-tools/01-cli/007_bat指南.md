# bat 使用笔记（Version 2.0）

> 本机版本：bat 0.26.1（Apple Silicon）
> 一句话：bat 是 `cat` 的增强版——语法高亮、行号、Git 变更标记，看代码和配置文件比 `cat` 舒服太多，还是本机 `fif` 的预览引擎。

---

## 一、常用指令速查表（先记这张表）

| 命令 | 作用 | 示例 |
|------|------|------|
| `bat 文件` | 高亮看文件内容 | `bat ~/.zshrc` |
| `bat -p 文件` | 纯文本输出（管道里必加） | `bat -p README.md` |
| `bat -n 文件` | 强制显示行号 | `bat -n script.sh` |
| `bat -l 语言 文件` | 指定语言高亮 | `bat -l md note.txt` |
| `bat -r 10:30 文件` | 只看第 10~30 行 | `bat -r 10:30 app.log` |
| `bat -H 20 文件` | 高亮第 20 行 | `bat -H 20 app.log` |
| `bat -A 文件` | 显示不可见字符 | `bat -A file` |
| `bat --list-themes` | 看所有主题 | `bat --list-themes` |
| `bat --theme=主题 文件` | 换主题 | `bat --theme=gruvbox 文件` |

## 二、详细解释

### 1. bat 是什么

`cat` 的现代替代品，Rust 写的。比 `cat` 多了三样：

- **语法高亮**：代码、JSON、YAML、Markdown 一眼看懂
- **行号**：默认就带（`cat` 要 `-n` 才有）
- **Git 集成**：文件改动行左边有 `+` / `-` 标记

一句话：看代码 / 配置，`cat` 换成 `bat`，体验直接上一个档次。

### 2. 和 cat 的区别

| 需求 | cat | bat |
|------|-----|-----|
| 看代码有高亮 | ❌ 纯黑白 | ✅ 彩色高亮 |
| 行号 | 要 `cat -n` | ✅ 默认就有 |
| 看 Git 改动 | ❌ | ✅ `+`/`-` 标记 |
| 分页（长文件） | ❌ 一屏刷完 | ✅ 自动进 less 分页 |

### 3. 常用选项分组

#### 输出控制
- `-p`（`--plain`）：纯文本，去掉行号/边框。**管道里一定要加**，否则会把装饰字符也传过去。
- `-n`：强制行号（默认长内容才显示）
- `-S`：长行不折行、横向滚动
- `-A`（`--show-all`）：显示换行、制表符等不可见字符

#### 范围 / 高亮
- `-r 10:30`：只看 10~30 行；`-r :20` 看前 20 行
- `-H 20`：高亮第 20 行（`-H 10:20` 高亮一段）

#### 语言 / 主题
- `-l 语言`：手动指定语言（文件没扩展名时用）
- `--list-languages` / `--list-themes`：看支持的语言 / 主题
- `--theme=主题`：换配色（本机 28 个主题可选）

### 4. 联动 ⭐（fif 的预览引擎）

本机 `fif`（rg + fzf + bat 三者流水线）里，bat 负责**预览**：

```
rg 搜出「文件:行:列:内容」→ fzf 选 → bat 高亮预览 → 回车 nvim 跳到该行
```

具体在 `~/.zshrc` 的 `fif` 函数里：`--preview 'bat --color=always --style=numbers --highlight-line {2} {1}'`。没有 bat，fif 就没有预览窗口。

## 三、进阶（按需了解）

- **当 man 的分页器**：让 man 手册也带高亮，`.zshrc` 加 `export MANPAGER="sh -c 'col -bx | bat -l man -p'"`（本机还没配）。
- **当 rg 的分页器**：`rg 词 | bat`，把搜索结果高亮分页看。
- **换默认主题**：`.zshrc` 加 `export BAT_THEME="gruvbox-dark"`，先 `bat --list-themes` 挑一个。
- **`alias cat='bat'`**：有些教程直接替换。本机没这么干，建议先 `cat`/`bat` 分开用，需要高亮时再敲 `bat`。

---

## 联动（呼应其他笔记）⭐

- **rg（004）+ fzf + bat**：三者组成 `fif`，bat 是预览引擎。
- **fd（005）**：`fd` 找文件名、`rg` 找内容、`bat` 看内容，是「定位 → 搜 → 读」三件套。
- **tldr（003）**：忘了 bat 的选项就 `tldr bat`。

---

## 总结：要不要用

- **必用**：只要看代码/配置文件，`bat` 就比 `cat` 值；而且它是 `fif` 的一环，装了就赚到。
- **学习成本**：零。`bat 文件` 跟 `cat 文件` 用法一样，白捡高亮。
- **注意**：管道里记得加 `-p`，别把装饰字符传给下游命令。
